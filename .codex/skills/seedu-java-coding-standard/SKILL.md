# SE Java Coding Standard

Apply the SE Education Java coding standard to all Java code in this project:

- Put every class in a meaningful lowercase package.
- Use PascalCase for class names, camelCase for variables and methods, and
  SCREAMING_SNAKE_CASE for constants. Name booleans with prefixes such as
  `is`, `has`, or `was`.
- Use four spaces for indentation, K&R braces, and lines no longer than 120
  characters. Keep imports explicit and consistently ordered.
- Initialize variables at declaration where practical and keep them in the
  smallest suitable scope. Use braces for every loop and conditional body.
- Keep class fields private and expose behavior through methods.
- Write English, American-spelling comments. Add descriptive Javadocs to all
  public classes and public methods, except getters/setters and applicable
  overrides.

For topics not covered here, follow the Google Java Style Guide. The source of
these project rules is <https://se-education.org/guides/conventions/java/intermediate.html>.
