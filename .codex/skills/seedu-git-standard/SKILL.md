# SE Git Standard

Use these conventions for every commit in this project:

- Write an imperative subject, capitalize its first letter, and do not end it
  with a period. Prefer 50 characters or fewer; never exceed 72 characters.
- Add a body for non-trivial commits, separated from the subject by a blank
  line. Wrap body lines at 72 characters.
- Explain what the commit changes and why. Describe the current situation in
  present tense and the change in imperative mood; do not explain the
  implementation mechanics when the diff already shows them.
- Split unrelated changes into separate commits where practical.

The source of these project rules is <https://se-education.org/guides/conventions/git.html>.
